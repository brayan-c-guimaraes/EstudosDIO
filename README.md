# 📊 Bootcamps DIO

Repositório dedicado aos estudos realizados em bootcamps da **Digital Innovation One (DIO)** com foco exclusivo em **dados**, abrangendo desde fundamentos até aplicações práticas em análise e engenharia de dados.

---

## 📚 Sobre o Repositório

Este repositório reúne exercícios, desafios e projetos desenvolvidos ao longo de diferentes trilhas da DIO na área de dados.

O objetivo é consolidar conhecimentos em:

* 📊 Análise de Dados
* 🐍 Python para Data Science
* 🧮 Lógica aplicada a problemas reais
* 📦 Manipulação e transformação de dados
* 🗃️ Estruturas de dados
* 📈 Introdução à Engenharia de Dados
